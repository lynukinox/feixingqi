# 云端飞行棋 · Cloud Hop

中文网页版飞行棋，使用 GitHub 开源框架 [Phaser](https://github.com/phaserjs/phaser)（MIT）驱动棋盘渲染、输入与本地移动动画，[Socket.IO](https://github.com/socketio/socket.io) 驱动联网房间，使用 [Vite](https://github.com/vitejs/vite)（MIT）开发与构建。依赖通过 npm 安装，字体使用系统字体，运行游戏不依赖在线 CDN。

## 运行

需要 Node.js 22.12+ 或 24+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址（通常为 http://127.0.0.1:5173）。

```sh
npm test       # 游戏规则和 20 局完整自动对战
npm run build # 生成 dist
npm run preview # 预览生产构建
```

运行开发服务器后，可执行 `npm run test:browser`，使用本机 Microsoft Edge 无界面检查本地交互，并在 `artifacts/` 中生成桌面与手机截图。

### 联网版本

```sh
npm run build
npm start
```

打开 http://127.0.0.1:3001 。同一个 Node 服务提供构建后的页面及 Socket.IO 房间服务。开发时在另一个终端运行 `npm run dev`，5173 端口会将 Socket.IO 请求转发到 3001。

各台手机打开同一公网地址，点击「好友联机」，输入昵称创建或加入房间。房主通过邀请链接、二维码或 6 位房间号邀请朋友，2–4 人在线后开始。仅打开本机的 127.0.0.1 地址不能让远方手机连接；需要将 3001 端口对应的游戏服务部署到服务器，或建立临时 HTTPS 隧道。

`npm run test:online` 会启动独立测试服务器，并使用两个手机尺寸的 Edge 浏览器验证建房、邀请、加入、同步、权限和刷新重连。

已完成一次通过 Pinggy 临时 HTTPS 地址的真实公网双端验收。当前入口及验证时间记录在 `PROGRESS.md`，临时入口到期后需重新建立。首次访问免费入口时点击「Enter site」。公网验收脚本为 `node scripts/public-check.mjs <当前HTTPS入口>`，使用真实服务器骰子，不改变生产规则。

## 功能

- 2–4 人同屏，或一位人类与电脑对战；默认一人对三台电脑。
- 中文界面、可缩放棋盘、手机布局、鼠标/触摸选择、Space 掷骰、可选合成音效。
- 飞机动画、行动记录、可移动飞机提示、编号按钮、胜利结算与重新开局。
- 电脑优先考虑归航、撞机、起飞和特别航线。
- 联网房间支持 2–4 台设备，服务器统一掷骰、判定合法移动并广播棋盘。
- 房间号、邀请链接、二维码、回合权限、刷新重连、60 秒操作超时代走。
- 手机联网对局的掷骰和选飞机按钮固定在屏幕下方。

## 本作规则

1. 四架飞机全部从机场出发；掷 6 可起飞一架到独立起飞区，或移动已起飞的飞机，之后额外投掷一次，连掷次数不限。
2. 外环按顺时针走；落在本色格时跳 4 格，起飞区除外。离开起飞区后的第 18 格（本色 ✈ 格）可飞到前方 12 格处，同色跳跃可以衔接飞行。飞行之后不额外再跳。
3. 普通移动的落点与跳跃/飞行的最终落点可撞回对手飞机；经过或飞越的格子不撞机。同色可叠放，仍逐架移动。
4. 绕行 50 格后进入本色的 6 格归航跑道；必须恰好到达最后一格，点数过多则反弹后退。四架全部到达即获胜。
5. 本版本无叠机封路、跨线撞机或三连六处罚。具体变体以游戏内说明为准。

## 项目结构

- `src/engine.js`：不依赖渲染的规则引擎与电脑决策。
- `src/board.js`：Phaser 棋盘、矢量生成的飞机和补间动画。
- `src/main.js`：界面交互、回合流程、弹窗与音效。
- `src/style.css`：桌面与手机界面样式。
- `tests/engine.test.js`：规则测试及完整自动对战。
- `server/index.js`：静态页面服务、权威房间状态、连接与回合管理。
- `src/online.js`、`src/online.css`：联网房间与手机邀请界面。
- `tests/online.test.js`、`scripts/online-check.mjs`：服务端联网测试与双端浏览器测试。

当前支持本地和联网房间，不包含账号、公开匹配大厅或数据库持久化。本地对局刷新会重开；联网对局在同一浏览器标签页刷新可恢复原席位。房间数据保存在服务进程内存中，重启服务会丢失；全部离线 20 分钟后清理房间。对局中主动离开会结束整桌游戏，临时断线则保留席位。

棋盘改编自 Mliu92 的传统飞行棋棋盘图（CC BY-SA 4.0），采用 52 格折角环道、独立起飞区、圆形落子点、四色归航箭头与直线飞跃航线。飞机图形由项目内 SVG 绘制。
