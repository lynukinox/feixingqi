# 云端飞行棋 · Cloud Hop

中文网页版飞行棋，使用 GitHub 开源框架 [Phaser](https://github.com/phaserjs/phaser)（MIT）驱动棋盘渲染、输入与本地移动动画，[Socket.IO](https://github.com/socketio/socket.io) 驱动联网房间，使用 [Vite](https://github.com/vitejs/vite)（MIT）开发与构建。依赖通过 npm 安装，字体使用系统字体，运行游戏不依赖在线 CDN。

## 运行

需要 Node.js 22.12+ 或 24+。

```sh
npm install
npm run dev
```

打开终端输出的本地地址（通常为 http://127.0.0.1:5173）。

```sh
npm test       # 游戏规则和 20 局完整自动对战
npm run build # 生成 dist
npm run preview # 预览生产构建
```

运行开发服务器后，可执行 `npm run test:browser`，使用本机 Microsoft Edge 无界面检查本地交互，并在 `artifacts/` 中生成桌面与手机截图。

### 联网版本

```sh
npm run build
npm start
```

打开 http://127.0.0.1:3001 。同一个 Node 服务提供构建后的页面及 Socket.IO 房间服务。开发时在另一个终端运行 `npm run dev`，5173 端口会将 Socket.IO 请求转发到 3001。

各台手机打开同一公网地址，点击「好友联机」，输入昵称创建或加入房间。房主通过邀请链接、二维码或 6 位房间号邀请朋友，2–4 人在线后开始。仅打开本机的 127.0.0.1 地址不能让远方手机连接；需要将 3001 端口对应的游戏服务部署到服务器，或建立临时 HTTPS 隧道。

`npm run test:online` 会启动独立测试服务器，并使用两个手机尺寸的 Edge 浏览器验证建房、邀请、加入、同步、权限和刷新重连。

已完成一次通过 Pinggy 临时 HTTPS 地址的真实公网双端验收。当前入口及验证时间记录在 `PROGRESS.md`，临时入口到期后需重新建立。首次访问免费入口时点击「Enter site」。公网验收脚本为 `node scripts/public-check.mjs <当前HTTPS入口>`，使用真实服务器骰子，不改变生产规则。

## 功能

- 2–4 人同屏，或一位人类与电脑对战；默认一人对三台电脑。
- 中文界面、可缩放棋盘、手机布局、鼠标/触摸选择、Space 掷骰、可选合成音效。
- 飞机动画、行动记录、可移动飞机提示、编号按钮、胜利结算与重新开局。
- 电脑优先考虑归航、撞机、起飞和特别航线。
- 联网房间支持 2–4 台设备，服务器统一掷骰、判定合法移动并广播棋盘。
- 房间号、邀请链接、二维码、回合权限、刷新重连、60 秒操作超时代走。
- 手机联网对局的掷骰和选飞机按钮固定在屏幕下方。

## 技能模式（2026-09-26）

单机：点击「开始新对局」，游戏玩法选择「技能模式」。联机：创建房间时选择「技能模式」，好友加入后采用房主的玩法。经典模式不发卡。

- 九种卡等概率、可重复抽取：定点骰子、路障、导弹、护盾、干扰、回收、全机起飞、三倍推进、窃取。
- 开局两张；所有玩家各完成一个回合算一轮，掷 6 连掷不额外计轮。每完成五轮，每人补一张。
- 每架飞机抵达终点或被撞毁，机主补一张。导弹击毁同样补卡；被护盾挡住、主动回收不补撞毁卡。
- 手牌上限五张，满手拿牌进入待选区：可弃旧牌换新牌，也可放弃新牌，多张逐张处理。待选牌仅本人可见，支持重连恢复；本地非当前玩家在轮到自己时处理。电脑自动选择，联机当前玩家操作超时保留原手牌、放弃待选牌。掷骰前也可主动弃牌，弃牌不补牌。先消耗卡，再结算效果，因此满手可窃取。
- 所有卡均在掷骰前使用，同一回合可连续使用多张，掷骰后须先完成移动；掷 6 连掷前可继续出牌。定点骰子选定飞机和 1–6 点，立即额外移动，不消耗正常掷骰、不推进回合；额外 6 点不奖励连掷。
- 路障放在公共航道空格，任何飞机经过或落下即撞毁回机场，并消耗路障；护盾不能抵挡，机主获得撞毁补卡。跳飞跨过路障不触发。
- 导弹以己方公共航道飞机为发射点，击毁前后三格以内（含同格）的所有其他飞机，包括友机，排除发射飞机；不攻击机场、起飞区与终点跑道。
- 三倍推进让下一次实际移动步数乘 3，可配合定点骰子，不叠加；起飞只到起飞区，不消耗加成，跳跃和飞越距离不翻倍。只有正常掷出 6 点奖励连掷，2 点乘三或定点骰子选六均不奖励。
- 护盾保护已起飞飞机，抵挡一次撞机或导弹，不可叠加；归航、回收后移除。
- 干扰随机弃掉一名对手一张卡；窃取随机取走一张。不允许对空手玩家使用。
- 回收撤回已起飞未归航飞机，抽两张；全机起飞将机场内所有飞机移至起飞区。
- 联机在服务器判定、抽卡和随机选牌，按席位单独发送手牌；对手只能收到牌数。刷新可恢复手牌、路障与护盾。
- 人机对战的电脑会使用技能。技能规则可在游戏内「玩法指南」查看。

验证：`npm test` 包含经典与技能规则、完整模拟对战、联机权限与手牌隔离。构建后执行 `node scripts/skills-check.mjs`，通过独立服务与两台手机尺寸浏览器检查全部九种卡、重连和界面。需本机 Microsoft Edge。

## 操作、动画与断线恢复

- 导弹、护盾、回收和路障的选牌弹窗可点击「在棋盘上选择目标」。导弹先点击己方飞机，再选择高亮敌机；也保留列表用于叠机等情况。
- 导弹飞行、护盾抵挡、路障与回收等结果有动画，窃取有飞卡提示。系统开启「减少动态效果」时不播放这些动画。
- 手机中手牌可横向滑动，掷骰与手牌紧邻棋盘，飞行员详细进度可展开查看。
- 补卡会显示原因、增加张数和满手情况，不公开卡牌种类。重连时不重播历史奖励。
- 结算按归航数和航程进度显示本局排名，并统计实际击毁数与主动用卡次数。护盾抵挡不算击毁。
- `npm start` 默认把联机对局原子保存到 `data/rooms.json`，可通过 `ROOM_STORE` 指定路径。每次状态发布前写入，支持服务重启后凭原来的浏览器席位令牌恢复。所有人离线时暂停操作计时，房间闲置 24 小时过期；主动离开改由电脑接管，其他真人继续；全部真人主动离开后关闭房间。
- 存档包含私人手牌与席位令牌，放在静态资源目录之外，`data/` 已加入 Git 忽略。测试实例默认不写生产存档。
- 恢复依赖存档文件仍存在。在会清空本地磁盘的免费云托管环境中，需要额外的持久化存储才能跨重建恢复；当前本机运行已支持重启恢复。
- 新增 `tests/recovery.test.js` 验证重启后棋盘、手牌、权限、统计、奖励和计时；手机浏览器测试包括直接点棋盘发射与结算表。

## 本作规则

1. 四架飞机全部从机场出发；掷 2、4、6 可起飞一架到独立起飞区，或移动已起飞的飞机，其中掷 6 后额外投掷一次，连掷次数不限。
2. 外环按顺时针走；落在本色格时跳 4 格，起飞区除外。离开起飞区后的第 18 格（本色 ✈ 格）可飞到前方 12 格处，同色跳跃可以衔接飞行。直接落在飞跃起点时，飞到第 30 格后再跳 4 格至第 34 格；先同色跳跃到起点再飞行的情况，停在第 30 格。
3. 普通移动的落点与每段跳跃/飞行的落点可撞回对手飞机；经过或飞越的格子不撞机。同色可叠放，仍逐架移动。
4. 绕行 50 格后进入本色的 6 格归航跑道；必须恰好到达最后一格，点数过多则反弹后退。四架全部到达即获胜。
5. 本版本无叠机封路、跨线撞机或三连六处罚。具体变体以游戏内说明为准。

## 项目结构

- `src/engine.js`：不依赖渲染的规则引擎与电脑决策。
- `src/board.js`：Phaser 棋盘、矢量生成的飞机和补间动画。
- `src/main.js`：界面交互、回合流程、弹窗与音效。
- `src/style.css`：桌面与手机界面样式。
- `tests/engine.test.js`：规则测试及完整自动对战。
- `server/index.js`：静态页面服务、权威房间状态、连接与回合管理。
- `src/online.js`、`src/online.css`：联网房间与手机邀请界面。
- `tests/online.test.js`、`scripts/online-check.mjs`：服务端联网测试与双端浏览器测试。

当前支持本地和联网房间，不包含账号、公开匹配大厅或数据库持久化。本地对局刷新会重开；联网对局在同一浏览器标签页刷新可恢复原席位。房间数据保存在服务进程内存中，重启服务会丢失；全部离线 20 分钟后清理房间。对局中主动离开会结束整桌游戏，临时断线则保留席位。

棋盘改编自 Mliu92 的传统飞行棋棋盘图（CC BY-SA 4.0），采用 52 格折角环道、独立起飞区、圆形落子点、四色归航箭头与直线飞跃航线。飞机图形由项目内 SVG 绘制。

### 离开后电脑接管

已开始的对局中主动离开，将保留席位、飞机、手牌和统计，由电脑自动掷骰、走棋与出牌。房主转交给剩余真人；旧席位令牌失效，离开者本局不能重新接管。暂时断网仍保留重连与 60 秒超时代走机制。真人全部离线时暂停，全部主动离开时删除房间。结算后房主可带电脑席位再开一局。

### 人机局面评估

电脑模拟所有合法移动，评估归航、进度、实际撞毁、护盾与路障，并枚举对手六种骰点的最佳撞机风险。掷六时额外前瞻一次投掷。出牌会比较所有合法卡牌/目标与不出牌的预期收益，随机补卡按数量估值，不窥看敌方隐藏手牌。属于有限前瞻策略，不保证全局最优。新增五项关键局面测试，原有完整自动对局与双端联机回归通过。
